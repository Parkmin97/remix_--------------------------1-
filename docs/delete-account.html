방법 1 — 앱에서 직접 삭제하기 (즉시 처리)

앱 실행 → 로그인 → 설정 및 서비스 정보 → 프로필 설정 → 회원 탈퇴

탈퇴를 확정하면 아래 정보가 즉시, 영구적으로 삭제됩니다.

  • 계정(이메일, 사용자 ID, 닉네임)
  • 잠금 기록 및 일별 리포트
  • 미션 수행 후 선택 기록
  • 기기에 저장된 프로필 사진과 앱 데이터

삭제된 정보는 복구할 수 없으며, 별도로 보관하는 사본은 없습니다.

잠금이 실행 중일 때는 탈퇴할 수 없습니다. 탈퇴가 잠금을 우회하는 수단이 되지 않도록 한 조치입니다. 잠금 시간이 끝나거나 지휘 미션에 성공한 뒤 진행해 주세요.

방법 2 — 이메일로 요청하기

앱을 이미 삭제하셨거나 앱에 접속할 수 없는 경우, 가입하신 이메일 주소로 아래 주소에 요청해 주세요.

받는 곳: aizhelp.2026@gmail.com
제목 예시: 계정 삭제 요청

본인 확인 후 처리하며, 접수일로부터 10일 이내에 처리 결과를 회신드립니다.

방법 3 — 계정은 유지하고 일부 데이터만 삭제하기

계정을 삭제하지 않고 특정 기록만 지우고 싶은 경우에도 요청하실 수 있습니다.

받는 곳: aizhelp.2026@gmail.com
제목 예시: 데이터 부분 삭제 요청

요청하실 수 있는 항목은 다음과 같습니다.

  • 잠금 기록 및 일별 리포트 전체 또는 특정 기간
  • 미션 수행 후 선택 기록
  • 입력하신 집중 목표 문구
  • 닉네임

가입하신 이메일 주소로 요청해 주시면 본인 확인이 빠릅니다. 접수일로부터 10일 이내에 처리하고 결과를 회신드립니다. 계정과 로그인 정보는 그대로 유지되므로 계속 서비스를 이용하실 수 있습니다.

닉네임과 프로필 사진은 요청 없이 앱 내 프로필 설정에서 직접 수정하거나 지우실 수 있습니다.
